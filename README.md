# Tic-Tac-Toe
A simple and interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

## Features
- Interactive Tic-Tac-Toe game board
- Player turn handling
- Winner detection
- Game result popup
- Restart/New Game functionality
- Clean and simple user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
